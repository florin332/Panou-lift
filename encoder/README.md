# Encoder ASC9

PlatformIO project for the Mega 2560 elevator encoder.

Firmware: transmitter v5.8.4

Features:
- LEGACY / CRC / BOTH transmission modes
- quiet-line event-driven transmission
- 3x burst on state change
- 2 s heartbeat
- CRC-8 polynomial 0x07
- TX frame / burst counters
- SH1106 128x64 I2C OLED

Board: Arduino Mega 2560
